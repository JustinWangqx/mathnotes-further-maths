# MathNotes — CIE Further Mathematics

A static study website for the **14 topics represented in the supplied notes**: 5 FP1, 4 FP2 and 5 Further Statistics topics. Topics without source notes are omitted.

Features include 14 English guides, 28 original worked examples, 48 original practice questions with hints and solutions, a formula index, official paper references, English/Chinese alias search, print layouts and device-local study status. No login, database or external font service is needed.

## Run locally

Use Node.js 24 LTS or another release supported by the locked Astro version.

```sh
npm ci
npm run dev
```

For a production preview with full-text search:

```sh
npm run check
npm run build
npm test
npm run preview
```

The development server supports topic-alias search. Pagefind full-text search is generated by `npm run build` and is available in the production preview.

## GitHub Pages

The included workflow builds, checks internal links and mathematical examples, and deploys `dist/` to GitHub Pages on pushes to `main`. Repository **Settings → Pages → Source** must be **GitHub Actions**.

For a manual build matching this repository’s Pages URL:

```sh
BASE_PATH=/mathnotes-further-maths/ SITE_URL=https://justinwangqx.github.io npm run build
BASE_PATH=/mathnotes-further-maths/ npm test
```

To deploy at another domain or path, change those environment variables and the corresponding workflow settings. Internal links, fonts, scripts and the search index all honour the base path.

## Edit content

- `src/content/notes/`: MDX guides with LaTeX maths, scope and source filenames.
- `src/data/curriculum.ts`: the supported topic list, navigation and Chinese search aliases.
- `src/data/practice.ts` and `extra-practice.json`: original questions and worked answers.
- `src/data/formulae.ts`: formula reference entries and conditions.
- `src/data/papers.ts`: official links and verified specimen question references.

Add the topic, guide, questions and aliases together. Every guide needs frontmatter matching `src/content.config.ts`; every source filename should be traceable in the local study collection. Use `$...$` for inline maths and `$$...$$` for display maths.

## Sources and review

The original PDF collection is deliberately excluded from the repository and deployment. The supplied coursebook and extracted exam questions are not redistributed. This site contains newly written explanations, diagrams and practice, with links to official Cambridge resources. See `docs/content-scope.md` for the exact topic selection.

The syllabus reference is CIE 9231 for 2026–2027. The guides are an initial editorial release, not a claim of exhaustive syllabus coverage or independent teacher review. Mathematical corrections should be submitted as GitHub Issues with a page, section and explanation.

## Checks

`npm run check` checks Astro and TypeScript. `npm test` checks all generated routes and anchors, deployment-base handling, 48 unique question/solution pairs, maths rendering, search aliases, absence of private assets, and numerical identities behind the worked examples.

The browser UI is designed for mobile and desktop, keyboard use and reduced-motion preferences. The HTML notes and native solution controls remain readable without JavaScript; filters and search require JavaScript.
